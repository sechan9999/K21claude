# 제21대 대통령선거 개표 대시보드

2025년 6월 3일 실시된 제21대 대한민국 대통령선거 개표 결과를 시각화하고, **재확인표(미분류표) 데이터의 OCR 오류를 검증·보정**한 인터랙티브 분석 대시보드입니다.

🔗 **라이브 데모**: https://k21-election-dashboard.vercel.app

---

## 주요 기능

### 득표 현황
- 후보자별 득표수·득표율 시각화
- 17개 시도별 상세 득표 분석 테이블
- 지역별 정당 강세 지역 분포

### 재확인표 OCR 오류 검증 (핵심)
- K21_대선_개표결과_상세.xlsx 재확인표 데이터의 OCR 오류 탐지 및 보정
- 전 17개 시도 김문수 재확인표 보정 완료
- 원본 개표상황표 PDF 직접 렌더링 검증 (pdfjs-dist + node-canvas)
- R1-R2 회귀분석: xlsx 원본 R²=0.00 → 보정 후 **R²=0.95** (역대 0.93~0.98 달성)

---

## 재확인표 검증 요약

AI OCR로 생성된 `K21_대선_개표결과_상세.xlsx`의 재확인표(심사집계부) 데이터에서 심각한 오류가 발견되었습니다.

### 오류 현황

| 후보 | xlsx 전국 재확인율 | 실제 범위 | 판정 |
|------|-----------------|---------|------|
| 이재명 | 2.4% | 2~5% | ✓ 정상 |
| 김문수 | 15.8% | 2~5% | ❌ OCR 오류 → **전 17개 시도 보정** |
| 이준석 | 26.1% | 3~7% | ❌ OCR 오류 |
| 권영국 | 63.1% | 3~6% | ❌ OCR 오류 |
| 송진호 | 78.4% | 4~10% | ❌ OCR 오류 |

### 보정 전후 비교

| 지표 | xlsx 원본 | 보정 후 |
|------|----------|--------|
| 전국 김문수 재확인표 | 2,277,439 | 304,605 |
| 전국 K값 | 7.72 | 0.89 |
| R²(R1-R2 회귀) | 0.00 | **0.95** |

### PDF 직접 검증 지역

개표상황표 원본 PDF를 렌더링하여 개별 투표함 K값을 실측:

| 지역 | 개별 투표함 K 실측 | xlsx K | 결론 |
|------|----------------|--------|------|
| 세종 | 0.34~2.34 | 7.076 | OCR 오류 확정 |
| 충북 | 0.34~2.34 | 8.199 | OCR 오류 확정 |
| 서울 | 1.5~2.4 | 3.144 | OCR 오류 확정 |
| 대구 | 1.04~2.18 | 3.004 | OCR 오류 확정 |
| 대전 | 0.82~1.72 | 2.643 | OCR 오류 확정 |
| 경남 | 0.49~1.9 | 2.923 | OCR 오류 확정 |

> **결론**: 선거 결과(득표수)는 공식 CSV와 완전 일치하여 정확하다.  
> 재확인표 통계 이상은 OCR 오류에서 비롯된 것으로, 부정선거와 무관하다.

## 기술 스택

- **Frontend**: React 18, Vite, Recharts, Tailwind CSS
- **PDF 검증**: pdfjs-dist, node-canvas
- **데이터 처리**: xlsx, Node.js
- **배포**: Vercel

## 프로젝트 구조

```
K21claude/
├── src/
│   ├── App.jsx              # 메인 대시보드 (재확인표 탭 포함)
│   └── data.json            # 선거 데이터 + 재확인표 보정 데이터
├── docs/
│   └── 재확인표_데이터_검증_종합보고서.md
├── 재확인표_데이터_검증_종합보고서.docx
├── render_pdf_page.mjs      # PDF → PNG 렌더링 스크립트
├── analyze21.cjs            # R1/R2/K값 분석 스크립트
├── update_data.cjs          # data.json 업데이트 스크립트
└── make_report_docx_final.cjs  # DOCX 보고서 생성 스크립트
```

## 설치 및 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
```

## PDF 검증 스크립트

```bash
# 특정 PDF 페이지를 PNG로 렌더링
node render_pdf_page.mjs <pdf_path> <page_num> <out.png>

# R1/R2/K값 분석
node analyze21.cjs

# DOCX 보고서 생성
node make_report_docx_final.cjs
```
